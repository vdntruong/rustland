# Deck

A deck of cards.

## Development Guidelines

Create a new crate/project

```bash
cargo new deck
```

Run project

```bash
cargo run
```

Run project without debug info (the flag `-q` stands for "quiet")

```bash
cargo run -q
```

Add crate to project

```bash
cargo add rand
```

Remove crate from project

```bash
cargo remove rand
```
